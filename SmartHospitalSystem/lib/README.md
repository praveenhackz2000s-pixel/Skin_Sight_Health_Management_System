# MySQL Connector/J

Download the Platform Independent ZIP archive from the official MySQL Connector/J page:
https://dev.mysql.com/downloads/connector/j/

Extract the ZIP and copy the file named `mysql-connector-j-<version>.jar` into this `lib/` folder.

This project intentionally does not include the third-party JAR. Every team member should download it, or the team can agree to add the downloaded JAR to the shared repository.
